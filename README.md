## Projects

### 1. [**Airbnb Data Engineering Project**](https://github.com/Sheik1sha/airbnb-dbt-snowflake)
Built an **end-to-end modern data engineering pipeline** using **AWS S3, Snowflake, dbt, Dagster, and Power BI** to transform raw Airbnb data into analytics-ready datasets and business insights.

**Highlights**  
- Ingested raw Airbnb CSV files from **AWS S3 into Snowflake** using **External Stage + COPY INTO / Snowpipe**  
- Built **staging and core dimensional models** using **dbt**  
- Implemented an **incremental fact table (`fct_reviews`)** with surrogate keys and date-based filtering  
- Enforced **data quality using dbt tests**: unique, not_null, relationships, accepted_values, positive_values  
- Orchestrated and monitored transformations using **Dagster**  
- Designed **Power BI dashboards** for host performance, pricing analysis, sentiment trends, and review behavior  

📊 *Tech Stack:* AWS S3 · Snowflake · dbt · Dagster · Power BI · SQL · Git · GitHub
